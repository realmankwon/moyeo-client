# 모여 · Mattermost 데스크톱 클라이언트

Mattermost 서버에 연결하는 독립 Electron 클라이언트입니다. 카카오톡처럼 개인·그룹 대화와 말풍선을 중심으로 구성했고, 로고나 전용 아이콘은 포함하지 않습니다. 설정에서 사용자가 직접 가져옵니다.

## 실행

Windows는 `Moyeo-0.15.14-Setup-x64.exe` 설치형, Mac은 Apple Silicon·Intel용 PKG 설치 파일과 DMG·ZIP을 제공합니다(macOS 13 이상). 포터블 배포는 중단했습니다. 두 운영체제 모두 새 버전을 확인해 앱 안에 알리고, **다운로드 페이지 열기**를 누르면 GitHub 릴리스 페이지를 기본 브라우저로 엽니다. 파일 다운로드와 설치는 사용자가 직접 진행합니다. Mac은 Developer ID 없이 ad-hoc 서명으로 빌드할 수 있으며 최초 실행 시 보안 승인이 필요할 수 있습니다. 배포 설정은 [새 버전 안내](docs/updates.md)를 참고하세요.

소스에서 개발할 때는 Node.js 22 이상과 npm이 필요합니다.

```powershell
npm install
npm start
```

서버 없이 확인하려면 로그인 화면의 **데모로 체험하기**를 선택하세요. 실제 연결은 서버 주소와 계정·비밀번호(MFA 선택), 또는 개인 액세스 토큰을 입력합니다. 주소에서 프로토콜을 생략하면 IP·localhost에는 HTTP, 도메인에는 HTTPS를 적용합니다. 서버가 다른 프로토콜을 사용하면 `http://` 또는 `https://`를 직접 입력하세요. 누락된 필드와 연결 단계, 네트워크 오류는 로그인 화면에 표시합니다. SSO 브라우저 로그인은 아직 지원하지 않습니다. API는 Mattermost 6.1 이상을 기준으로 사용하며 서버별 호환성 확인이 필요합니다.

## v0.15.14 이미지 뷰어 안정화·파일 일괄 저장

이미지 화면 맞춤·확대·창 크기 변경 시 스크롤바와 크기 계산의 반복을 방지하고, 확대 후 이동한 위치를 유지합니다.

한 메시지에 여러 파일이 있으면 **첨부 N개 전체 저장**으로 폴더를 한 번 선택해 원본을 저장하거나 **골라 저장**으로 해당 메시지 파일만 그리드에 모아 선택합니다. **사진·파일 → 파일 선택**에서도 이미지·문서를 함께 최대 500개 선택하고 저장할 수 있습니다. 검색·분류를 바꿔도 선택은 유지하며 **현재 목록 전체 선택**을 지원합니다. 같은 이름은 번호를 붙여 기존 파일을 보존합니다. 진행 표시·취소·실패 파일 재시도·저장 폴더 열기를 제공하고 계정 변경 시 진행 중인 전송을 중단합니다.

## v0.15.13 프로필 사진·상태 메시지

왼쪽 아래 내 프로필을 클릭한 뒤 **프로필 사진·상태 변경**에서 수정합니다. **설정 → 내 계정 설정**에서도 같은 화면을 엽니다. 사진 선택·정사각형 미리보기·서버 저장·기본 사진 복원을 지원합니다. 선택만으로 업로드하지 않습니다.

상태 이모지와 메시지(100자), 자동 해제 시간(계속 유지·30분·1시간·4시간·오늘·이번 주·날짜 지정)을 설정하거나 지울 수 있습니다. 일반·서버 이모지를 지원하며, 작성자·DM 목록·대화창 제목·내 프로필 옆에 상태 이모지를 표시합니다. 이름 옆 이모지에 마우스를 올리면 상태 메시지를 확인할 수 있습니다. 다른 클라이언트의 변경과 재연결 후 정보도 갱신하고, 현재 대화·초안·스크롤 위치는 유지합니다.

## v0.15.12 기기 간 읽음 동기화

같은 계정으로 여러 기기에서 실행할 때, 한 기기에서 채팅방을 읽으면 다른 기기의 새 글 배지·상단 알림·트레이 알림도 정리합니다. 서버의 단일/여러 채널 읽음 WebSocket 이벤트를 사용하고 읽음 시각 이후의 새 메시지는 남깁니다. 다른 기기의 읽음으로 현재 방이나 작성 내용이 바뀌지 않습니다.

재연결·앱 복귀 시 읽음 상태를 복구합니다. 서버가 읽음 이벤트를 보내지 않는 경우에는 미확인 알림이 남아 있는 방만 1분 간격으로 보조 확인하고, 모두 읽으면 중단합니다. 서버 DB에 직접 접속하지 않으며 공식 채널 멤버 API를 사용합니다.

## v0.15.11 Esc로 채팅창 닫기

채팅 화면에서 `Esc`를 누르면 닫기 버튼과 동일하게 동작합니다. 메인 창은 트레이로 숨겨 실행과 작성 중인 내용을 유지하고, 별도로 연 플로팅 채팅창은 해당 창을 닫습니다. 설정·미리보기나 이모지·멘션 선택기가 열려 있으면 먼저 그 화면을 닫습니다.

## v0.15.10 최근 이모지·미리보기 Esc 닫기

이모지 선택기를 열면 맨 위에 **최근 사용** 영역이 먼저 나타납니다. 최근 선택 순서로 최대 30개를 보여주며 중복 사용은 맨 앞으로 옮깁니다. 일반·서버 이모지와 계정별 저장을 지원하고 최근 사용 탭도 첫 번째에 배치했습니다.

이미지·동영상·문서 미리보기에서 `Esc`를 누르면 미리보기만 닫고 이전 채팅이나 사진·파일 모아보기로 돌아갑니다. 확대 버튼이나 동영상 컨트롤에 초점이 있어도 작동하며 재생 중인 미디어와 확대 관찰자를 정리합니다.

## v0.15.9 이미지 단계별 확대·축소

이미지 보기의 **− / +**로 10%~500% 범위에서 배율을 단계별로 조절합니다. 현재 배율 표시, **100%** 원본 크기, **화면 맞춤**을 제공하며 확대된 이미지는 가로·세로 스크롤로 끝까지 볼 수 있습니다. 키보드 `+`·`−`, `1`(100%), `0`(화면 맞춤), Ctrl/⌘+마우스 휠도 지원합니다. 다른 이미지로 이동하면 화면 맞춤으로 돌아갑니다.

## v0.15.5 사용자 목록 오류 수정

사용자 목록 요청의 지원하지 않는 정렬값을 제거하고 서버 기본 계정명 정렬을 사용합니다. 목록을 불러오지 못하면 오류 안내와 **다시 시도**를 표시합니다. Mattermost 11.5.1의 요청 검증에 맞춰 페이지·활성/비활성 필터 및 오류 후 재시도를 검증합니다.

## v0.15.4 앱 내 서버 관리·이미지 복사·답장 원본 이동

설정의 **서버 전체 관리**에서 사용자·역할, 채널·멤버, 파일 저장소, SMTP를 Moyeo 자체 화면으로 조회·수정합니다. 모든 관리 요청은 서버의 최신 시스템 관리자 역할을 확인하고 공식 API로 반영합니다. 일반 계정의 내 계정 설정과 서버 전체 설정을 분리하고, 환경 변수로 고정된 항목은 잠금 표시합니다. 기존 비밀번호·S3 비밀키는 화면으로 전달하지 않습니다.

이미지 보기 상단 **이미지 복사** 또는 Ctrl+C(Mac ⌘C)로 원본 이미지를 PNG 클립보드에 복사합니다. 저장은 필요 없으며, GIF를 복사하면 정지 이미지가 됩니다. 복사는 30MB까지 지원합니다.

답장 인용 영역의 작성자 옆 **원본으로 이동 ↗**을 누르면 앱 안에서 원본 메시지 위치를 불러와 강조합니다. 현재 목록에 없는 오래된 원문도 조회하며, 상단 **← 뒤로** 또는 Alt+왼쪽 화살표로 이전 대화방과 보던 메시지 위치로 돌아갑니다. 작성 중인 내용은 유지합니다. 삭제되었거나 접근할 수 없는 원문은 안내를 표시합니다.

## v0.14.6 대화 목록 개선

채널별 파스텔 색상과 이니셜 아바타, 작은 공개·비공개 표시로 대화를 구분합니다. 제목과 시간을 같은 줄에 배치하고 팀 정보와 메시지를 한 줄로 합쳐 행 높이를 줄였습니다. 비어 있는 메시지 대신 반복되던 공개·비공개 설명을 제거했습니다. 즐겨찾기하지 않은 별은 마우스나 키보드로 접근할 때 표시합니다.

## v0.14.5 자동 새 버전 알림

앱을 계속 켜둬도 1분마다 새 배포를 확인합니다. 앱에 돌아오거나 잠자기에서 깨어날 때도 다시 확인합니다. 메신저 상단 안내와 백그라운드 OS 알림으로 알리며, 이미 확인한 안내는 일시적인 조회 오류로 사라지지 않습니다. 이 동작은 0.14.5를 한 번 설치한 뒤 적용됩니다.

## v0.14.4 설치 개선

Mac에서는 `.pkg` 설치 파일을 권장합니다. macOS 설치 프로그램이 실행 중인 Moyeo의 종료를 확인한 뒤 `/Applications/Moyeo.app`을 교체합니다. 설치가 끝나면 응용 프로그램 폴더에서 다시 실행하세요. DMG·ZIP은 직접 완전히 종료한 뒤 교체해야 합니다. 새 버전 안내의 **설치를 위해 완전히 종료** 버튼으로도 종료할 수 있습니다. 개인 설정과 로그인 정보는 유지합니다.

## v0.14.3 화면 개선

대화 목록의 검색·필터·선택 상태와 채널 아이콘을 다듬었습니다. 팀별 영역에서는 반복되는 팀 이름을 줄이고, 최근 메시지는 Markdown 기호를 걷어낸 한 줄 미리보기로 표시합니다. 목록이 갱신돼도 스크롤 위치와 키보드 초점을 유지하며 검색·필터를 바꾸면 처음부터 표시합니다.

## 계정과 대화 목록

프로필 이미지는 현재 로그인 권한으로 불러옵니다. 불러올 수 없으면 이름의 첫 글자를 표시합니다. 개인 DM은 계정마다 하나의 대화방으로 표시하며 `@아이디`로 동명이인을 구분합니다. 공개·비공개 채널은 팀별로, 그룹 대화는 별도 영역으로 표시합니다. 즐겨찾기에서는 팀 이름도 함께 표시합니다.

목록이나 대화방 상단의 별을 누르면 즐겨찾기를 추가·해제합니다. 즐겨찾기는 현재 Mattermost 계정의 `favorite_channel` 환경설정에 저장되어 이 앱으로 다시 접속해도 유지됩니다. 실패하면 기존 상태를 유지합니다. 대화방 새로고침은 프로필과 즐겨찾기도 다시 불러옵니다. 계정 전환은 로그아웃 후 다른 계정으로 로그인하는 방식이며 동시 다중 계정 연결은 아직 지원하지 않습니다.

## 작성·이모지·파일 보내기

작성창의 도구로 텍스트를 선택해 굵게(`Ctrl+B`)·기울임(`Ctrl+I`)·취소선·인라인 코드·코드 블록·인용문·목록·링크 효과를 적용합니다. **미리보기**에서 결과를 확인하고 보낼 수 있습니다. 효과는 Mattermost Markdown으로 전송됩니다. HTML과 임의 글자색·폰트 지정은 지원하지 않습니다. 메시지 링크는 클릭하면 기본 브라우저로 엽니다.

웃는 얼굴 버튼은 이모지 선택기를 엽니다. 한글 키워드·영문 이름으로 검색하고, 최근 사용·카테고리·서버 이모지에서 선택합니다. 검색창 Enter는 첫 검색 결과를 삽입합니다. 이모지에 마우스를 올려 작은 별을 누르면 **즐겨찾기 이모지**에 등록·해제합니다. 최근 사용과 즐겨찾기는 서버·계정별로 이 PC에 보관합니다. 사용자 이모지는 서버가 허용한 권한과 파일 제한에 따라 추가합니다.

**GIFs** 탭은 GIPHY 인기 GIF와 검색 결과를 2열 그리드로 표시합니다. Mattermost의 공개 클라이언트 설정 `GiphySdkKey`를 읽어 사용하며 앱에 공용 테스트 키를 내장하지 않습니다. 서버의 GIF 기능이 비활성화되어 있거나 키가 없으면 안내를 표시합니다. 인터넷 연결과 정상적인 서버 GIPHY 설정이 필요합니다. API 요청과 미리보기는 GIPHY로 보내되 Mattermost 인증 토큰은 전달하지 않습니다. 검색 결과는 GIPHY 순서를 유지합니다.

GIF의 별을 눌러 등록하고 **즐겨찾기**·**최근 사용**에서 바로 선택할 수 있습니다. 선택한 GIF는 첨부 대기 목록에 추가하며 **전송**을 누르면 Mattermost에 파일로 업로드합니다. 따라서 다른 Mattermost 클라이언트에서도 첨부로 확인할 수 있습니다. 선택한 GIF는 최대 25MB이며, GIF 파일 첨부 버튼도 계속 사용할 수 있습니다. 즐겨찾기는 GIF ID를 저장하고 이미지 파일 자체는 보관하지 않습니다.

클립 버튼으로 파일을 고르면 전송 대기 목록에 추가됩니다. 이미지는 클립보드 붙여넣기, 파일은 대화 영역으로 드래그해서도 추가할 수 있습니다. **전송**을 눌러 실제 업로드하고 메시지에 첨부합니다. 텍스트 없이 파일만 보낼 수도 있습니다. 앱에서는 메시지당 최대 10개를 선택하며 서버의 크기·개수·권한 제한도 적용됩니다. 붙여넣기·드래그는 파일당 25MB까지이고, 더 큰 파일은 클립 버튼을 사용합니다. 클립 버튼은 파일을 메모리에 한꺼번에 읽지 않고 업로드합니다.

업로드 또는 메시지 생성이 실패하면 입력과 첨부를 유지합니다. 이미 업로드한 파일은 메시지 재시도 때 중복 업로드하지 않습니다. 파일 선택만으로는 서버로 전송하지 않으며, **전송**을 누를 때 업로드합니다. 사용자 이모지 추가는 별도의 명시적 업로드 동작입니다.

## 프로필과 대화방 테마

프로필 사진을 클릭하거나 키보드로 선택해 Enter를 누르면 이름·아이디·이메일·직책·별명·상태 등 서버에서 공개한 정보를 표시합니다. 다른 사람의 프로필에서 **개인 메시지 보내기**로 DM을 엽니다. 서버가 숨긴 정보나 상태는 표시하지 않습니다.

대화방 위 **🎨 대화방 꾸미기**에서 기본·민트·라벤더·로즈·밤 프리셋을 선택하거나 배경, 내/상대 말풍선, 글자색, 헤더·입력창 색상, 12~20px 글자 크기와 도트 무늬를 지정합니다. 변경 내용을 바로 미리 보고 **테마 저장**을 누르면 현재 방에만 저장합니다. 닫거나 Esc를 누르면 저장 전 미리보기를 취소합니다. **전체 테마 따르기**는 해당 방의 개별 설정을 지우고 전체 테마를 적용합니다. 테마와 GIF·이모지 즐겨찾기는 `userData/personal-settings.json`에 서버·계정별로 저장하며 다른 참여자에게 적용되지 않습니다.

**설정 → 전체 대화창 꾸미기**에서 **모든 대화창에 적용**을 누르면 현재 계정의 채널·개인 대화·별도 대화창을 한 번에 변경합니다. 대화방 위 꾸미기 버튼에서도 **전체 대화창**을 선택할 수 있습니다. 기본으로 기존 방별 테마도 함께 변경하며, **대화방별로 지정한 테마도 함께 변경**을 끄면 방별 예외를 유지합니다. 열려 있는 창에는 즉시 반영되고 새로 여는 창과 앱 재실행 후에도 유지됩니다. **전체 기본값으로**를 누르면 기본 화면으로 돌아갑니다. 이 설정은 현재 PC와 계정에만 저장되며 다른 참여자의 화면은 바꾸지 않습니다.

## 메시지 작업

메시지를 **우클릭**하면 **이모지 반응·답장·공유·내용 복사·원문 링크 복사·수정·삭제** 메뉴가 나타납니다. 메시지 안의 웹 링크를 우클릭하면 **링크 주소 복사**가 맨 위에 추가됩니다. 표시된 글자 대신 실제 연결 주소를 복사하며, 주소의 쿼리와 앵커도 유지합니다. 링크를 선택한 상태에서 `Shift+F10` 또는 메뉴 키로도 복사 메뉴를 열 수 있습니다. 주소를 복사할 때 브라우저를 열거나 로그인하지 않습니다. 하이웍스 설정은 필요 없으며, 복사한 메일 링크를 열 때 필요한 하이웍스 로그인은 별개입니다. 키보드로 메시지를 선택해 `Shift+F10` 또는 메뉴 키로 열 수도 있습니다. 메뉴에서 위·아래 키로 이동하고 Esc로 닫습니다. 마우스 호버 작업 표시줄은 제거했습니다. 답장은 작성창의 원문 표시와 함께 입력하며 Mattermost `root_id`로 전송합니다. 수신·전송한 답글 위에는 원문 작성자·본문·첨부 미리보기를 자동 표시합니다. 현재 메시지 목록에 없는 원문도 조회하며 삭제·접근 불가 시 안내합니다. 긴 원문은 미리보기 영역 안에서 스크롤할 수 있습니다. 원문·답글 보기 버튼은 전체 스레드를 엽니다. 답장 대기는 대화방별로 유지되고 취소할 수 있습니다.

GIPHY 검색 결과는 썸네일 행 높이를 유지하고 목록 안에서 스크롤합니다. 결과가 20개 이상이어도 행이 얇게 눌리지 않으며, GIF 전체가 보이도록 비율을 유지해 표시합니다.

사진·동영상 모아보기도 고정된 카드 높이를 유지합니다. 209개 이미지가 있는 방으로 카드·썸네일 높이와 마지막 항목까지 스크롤되는지 검증했습니다. 메타데이터를 확인 중인 파일과 실제 조회 실패 파일을 구분해 표시합니다.

## 이모지 반응과 새 메시지 알림

메시지 우클릭 메뉴의 **이모지 반응** 또는 말풍선 아래 **☺＋**에서 이모지를 선택합니다. 기본 이모지와 불러온 서버 사용자 이모지를 검색하고, 즐겨찾기 이모지를 사용할 수 있습니다. 이미 누른 반응을 다시 누르면 **내 반응만** 취소합니다. 서버에 저장되며 다른 Mattermost 클라이언트에서도 확인됩니다. 서버의 권한 제한이 적용되고 저장에 실패하면 기존 상태를 유지합니다.

반응 칩은 이모지별 개수와 내가 눌렀는지를 표시합니다. 칩 옆 **⌄** 또는 **반응한 사람**을 누르면 이모지별·전체 목록에서 이름·아이디·어떤 반응을 눌렀는지 확인합니다. 계정을 누르면 프로필을 엽니다. 반응 목록은 대화 조회와 WebSocket 반응 이벤트로 갱신합니다.

접속 후 새 메시지가 오면 앱 맨 위에 강조 알림을 표시하고, 왼쪽 목록의 **새 메시지** 영역을 즐겨찾기보다 위에 둡니다. 가장 최근 도착한 방이 먼저 표시됩니다. 상단 알림의 **바로 가기**를 누르면 검색·종류 필터를 해제해 해당 방으로 이동합니다. 작성 중인 메시지와 첨부 대기는 원래 방에 보존됩니다. 알림 숨기기는 읽음 처리하지 않으며, 새 메시지가 다시 오면 표시합니다. 현재 방을 선택해 확인하면 그 방의 알림을 제거합니다.

앱이 비활성 상태면 작업 표시줄을 강조하고 지원되는 환경에서는 시스템 알림을 표시합니다. 시스템 알림 클릭도 같은 방으로 이동합니다. 시스템 알림 표시 여부는 Windows 알림 설정에 따릅니다. 창 제목의 숫자는 미확인 **대화방 수**이며 메시지 개수와 다릅니다. 현재 보고 있는 방의 맨 아래를 읽고 있으면 중복 알림을 생략합니다. 알림은 WebSocket 새 메시지 이벤트로 표시하며 접속 이전의 미확인 메시지 전체를 재구성하지 않습니다.

## 트레이·알림 소리·앱 데이터

창의 **X**를 누르면 앱을 종료하지 않고 트레이로 숨깁니다. 로그인과 작성 중인 내용, 메시지 수신을 유지합니다. 트레이 아이콘 클릭·더블클릭 또는 메뉴의 **모여 열기**로 복원하며, 앱을 다시 실행해도 기존 창을 엽니다. 종료하려면 트레이 우클릭 메뉴에서 **완전히 종료**를 선택합니다. Windows 종료는 방해하지 않습니다.

미확인 새 메시지에는 번들 알림음을 재생합니다. 동시에 여러 방에서 도착한 경우 짧은 간격의 중복 소리는 합칩니다. 트레이의 **알림 소리** 체크 또는 설정의 **새 메시지 알림 소리**에서 켜고 끕니다. 알림 클릭은 숨겨진 창을 복원하고 해당 방을 엽니다. 트레이 메뉴의 새 메시지 대화방으로도 이동할 수 있습니다. 시스템 알림은 자체 소리와 중복되지 않게 무음으로 표시하고, 지원 실패 시 트레이 알림으로 대체합니다.

설치형은 Windows의 `%APPDATA%/moyeo-mattermost-client`, Mac의 `~/Library/Application Support/moyeo-mattermost-client`에 데이터를 보관합니다. 앱 업데이트는 이 폴더를 교체하지 않습니다. 이전 포터블 사용자는 로그아웃 상태의 화면 설정에서 **이전 포터블 데이터 가져오기**로 기존 EXE 옆 `Data` 폴더를 선택할 수 있습니다. 외형·개인 설정·최근 이모지·암호화된 로그인 파일만 복사하고 현재 파일은 덮어쓰지 않습니다. 암호화된 로그인 정보는 같은 운영체제 사용자 계정에서만 복원할 수 있습니다. 배포 파일에는 개인 `Data`와 인증 정보를 포함하지 않습니다.

수정과 삭제는 내 일반 메시지에만 표시하며 서버의 권한·편집 시간 제한도 적용됩니다. 수정 시 첨부는 유지하고 본문만 바꿉니다. `Ctrl+Enter`로 수정 저장을 지원합니다. 삭제는 별도의 확인창에서 **삭제**를 눌러야 서버에서 실행됩니다. 실패하면 창과 입력을 유지합니다.

**공유**는 선택한 대화방에 내용을 인용하고 원문 링크를 포함한 새 메시지를 보냅니다. 첨부 파일 자체를 복제하지 않으며 원문 권한이 있는 사용자가 링크에서 확인합니다. 원문에 대한 접근 권한을 새로 부여하지 않습니다. **복사**는 본문을, **링크**는 원문 주소를 클립보드로 복사합니다.

## 사진·동영상·파일 보기

채팅에서 썸네일을 클릭하면 미리보기가 열립니다. 사진은 확대할 수 있고, 영상과 음성은 재생 컨트롤로 조작합니다. 좌우 버튼 또는 키보드 화살표로 사진과 영상을 연속해서 봅니다. 다른 자료로 이동하거나 창을 닫으면 이전 영상·음성은 멈춥니다. `Esc`로 미리보기를 닫습니다.

대화방 오른쪽 위 **사진·파일**을 누르면 그 방의 자료만 모아서 봅니다. 기본은 사진·동영상 그리드이며 종류별 탭에서 문서 등을 찾을 수 있습니다. 처음에는 최대 300개 메시지를 확인하며, 오래된 대화는 **이전 자료 더 불러오기**로 계속 확인합니다. 뷰어에서 마지막 미디어 다음으로 이동할 때는 이전 대화를 자동으로 추가 검색합니다. 표시되는 개수는 현재 확인된 자료 기준입니다.

PDF는 저장하기 전에 페이지 이동·페이지 번호 입력·확대/축소로 확인합니다. DOCX는 본문·표, XLSX는 시트별 셀, PPTX는 슬라이드별 텍스트, HWPX는 본문 내용을 미리 봅니다. Office·HWPX 미리보기는 이미지·차트·일부 서식을 생략하는 내용 미리보기입니다. XLSX는 최대 20시트, 시트당 처음 200행·50열까지 표시합니다. 문서 파일은 30MB까지 지원하며 내부 XML 내용 크기도 제한합니다. 텍스트는 1MB 이하 UTF-8 파일을 미리 봅니다. HWP·DOC·XLS·PPT 등 이전 바이너리 형식과 지원하지 않는 문서는 저장 후 연결된 앱에서 확인합니다.

미리보기 상단의 **저장**은 파일을 저장하고 파일명·저장 경로와 **파일 열기**·**폴더 열기**를 표시합니다. **저장 후 열기**는 저장이 끝나면 운영체제의 연결된 앱으로 원본을 바로 엽니다. 기본 앱이 없거나 파일이 이동·삭제되었으면 이유를 표시합니다. 검색 결과에도 **미리보기**를 제공합니다. 실행 파일 등 직접 열기를 제공하지 않는 형식은 저장 폴더에서 확인할 수 있습니다. 이미지·영상·음성 재생 가능 여부는 Electron의 지원 코덱에 따릅니다. 지원하지 않는 형식과 접근 불가 파일에는 안내가 표시됩니다. Mattermost에 업로드된 첨부와 허용된 GIPHY 링크의 GIF 미리보기를 지원합니다.

미디어 요청은 메인 프로세스에서 인증하며 URL에 서버 토큰을 넣지 않습니다. 영상·음성은 스트리밍하고 바이트 범위 요청을 전달해 구간 이동을 지원합니다. 로그아웃 시 뷰어와 자료 목록을 비우고 기존 미디어 URL을 무효화합니다.

비밀번호는 저장하지 않습니다. 로그인 기억을 켜면 서버의 세션/개인 토큰을 운영체제 암호화 기능으로 보호해 사용자 데이터 폴더의 `login.bin`에 저장하고, 다음 실행 시 자동 로그인합니다. 같은 운영체제 사용자 계정에서만 복원할 수 있습니다. 로그아웃하거나 자동 로그인을 끄면 저장한 토큰을 삭제합니다. 세션이 만료되면 다시 로그인해야 하며, 일시적인 연결 실패는 자동 로그인 다시 시도로 재연결할 수 있습니다. 개인 토큰 로그아웃은 로컬 연결만 해제하고 토큰을 폐기하지 않습니다. 사내 HTTP 서버도 연결할 수 있지만 외부 네트워크에서는 HTTPS 서버를 사용하세요.

## 현재 범위

그룹 생성과 SSO 브라우저 로그인은 아직 없습니다. 스레드는 대화상자로 제공합니다. Markdown은 위의 기본 텍스트 효과를 지원하며 전체 Mattermost 렌더러와 같지는 않습니다.

읽음 배지는 로그인 후 관찰된 새 활동만 표시합니다. 서버의 기존 미확인 메시지 수와 연동하지 않았고, 상대방 읽음 여부를 나타내지 않습니다. 표시 이름은 현재 사용자 이름을 사용합니다.

OS 알림 팝업은 테스트에서 억제하고 알림 클릭의 앱 이동 경로를 검사합니다. `test:updates`는 로컬 HTTP 서버의 릴리스 응답으로 Windows와 두 Mac 아키텍처의 새 버전 탐색·다운로드 페이지 안내·응답 오류 처리를 검사합니다. 앱이 바이너리를 내려받거나 설치·재시작하지 않는지도 확인합니다. `dist:win`은 Windows 설치형, `dist:mac`은 Mac PKG·DMG·ZIP을 만듭니다. [배포 안내](docs/updates.md)를 참고하세요. 앱 내 로고 변경은 실행 중인 창과 앱 화면에 적용되며 배포 아이콘은 Moyeo 말풍선 심볼을 사용합니다. `build/icon.svg`와 `build/tray.svg`를 수정한 뒤 `npm run generate:icons`로 Windows ICO·Mac ICNS·Retina 메뉴 막대 이미지를 함께 생성합니다.

API 참고: [Mattermost API](https://docs.mattermost.com/api), [채널 조회](https://docs.mattermost.com/api/reference/get-channels-for-user), [Electron 보안](https://www.electronjs.org/docs/latest/tutorial/security).

윈도우 시작 시 자동 실행은 설정의 **윈도우 시작 시 트레이로 실행**에서 켜거나 끕니다. 자동 로그인과 함께 켜면 Windows 로그인 후 트레이에서 연결됩니다. 설치 위치를 변경했다면 시작 실행 옵션을 다시 저장하세요.
`node tests/session-ui.cjs`는 Windows 실제 암호화, 재실행, 만료, 시작 항목 임시 등록 및 제거를 검증합니다.

## Windows와 Mac 동시 배포 및 새 버전 안내

Windows NSIS 설치형과 macOS arm64·x64 PKG/DMG/ZIP을 같은 버전·소스로 만듭니다. Mac 앱과 중첩 코드는 ad-hoc 서명하고 네이티브 서명을 검증합니다. Developer ID·Apple 공증은 기본 구성에서 사용하지 않으며 최초 실행 허용이 필요할 수 있습니다. Windows 실행·설치 검증은 Windows에서 별도로 해야 합니다.

GitHub 조회 대상은 `package.json`의 `releaseRepository`이며 기본값은 `realmankwon/moyeo-client`입니다. `MOYEO_UPDATE_REPOSITORY=owner/repo` 환경 변수로 빌드 시 변경할 수 있습니다. 공개 릴리스만 읽으며 GitHub 토큰·Mattermost 서버 주소·로그인 정보·대화를 전송하지 않습니다. 앱은 실행 약 2초 뒤와 1분마다 확인하며, 앱 복귀·창 복원·잠자기 복귀 때도 확인합니다(연속 이벤트는 30초 이내 중복 조회하지 않습니다). 새 정식 버전의 해당 운영체제·아키텍처 설치 파일이 준비되면 알림을 표시합니다. 알림을 누르면 기본 브라우저에서 릴리스 페이지를 열며, 사용자가 내려받아 직접 설치합니다. 자동 다운로드·설치·재시작은 하지 않습니다.

`npm run release:all`은 macOS에서 Windows 설치형과 두 Mac 패키지를 함께 생성합니다. Developer ID 인증서 없이 빌드할 수 있습니다. `npm run release:preview`는 별도 폴더에 새 버전 조회를 비활성화한 테스트 파일을 만듭니다.

`npm run verify:release`는 포함된 소스 일치와 알림 설정·민감 파일 제외·Windows CPU·Mac ZIP 전체 CRC·실행 권한·심볼릭 링크·CPU·네이티브 서명·DMG를 확인합니다. 테스트 빌드 검증에는 `-- --preview`를 추가합니다.

설정·CI·게시 절차는 [새 버전 안내](docs/updates.md)를 참고하세요. 이 저장소를 공개하거나 릴리스를 업로드하는 작업은 빌드 명령에 포함되지 않습니다.

반응 추가 버튼은 메시지를 가리킬 때 표시하며 키보드 포커스와 터치 조작도 지원합니다. 같은 분에 연속된 메시지는 첫 메시지에만 시간을 표시합니다. 메시지 또는 작성 영역을 클릭하면 해당 방의 상단 새 메시지 알림·배지를 지우며, 앱이 활성화되어 보고 있는 방은 상단 알림을 만들지 않습니다. 다른 방과 트레이·비활성 창의 알림은 유지됩니다.
GIF 첨부는 정지 썸네일 대신 원본 GIF를 표시해 채팅·자료 모음·탐색 스트립에서 애니메이션을 유지합니다. GIPHY 첨부도 원본 GIF를 우선 다운로드합니다. 일반 http/https URL과 Markdown 링크는 클릭해 기본 브라우저로 열 수 있습니다. 코드 블록의 주소는 링크로 바꾸지 않습니다.
새 메시지 수신 시 최신 위치에 있으면 자동으로 아래를 따라갑니다. 이미지·GIF·답글 로딩이나 창 크기 변경으로 높이가 달라져도 최신 위치를 유지합니다. 사용자가 이전 대화를 보려고 위로 스크롤하면 그 위치를 유지하고, 다시 아래로 내려오면 최신 메시지를 따라갑니다. 기존 GIPHY GIF 링크 메시지도 채팅에서 애니메이션 미리보기를 표시합니다.

공유된 같은 Mattermost 서버의 메시지 링크는 브라우저 대신 앱 안에서 해당 방 원문과 주변 대화를 불러와 강조합니다. 원문 보기에서 최신 메시지로 돌아갈 수 있습니다. 다른 사이트의 링크는 브라우저로 엽니다. 메시지 표시 이름은 닉네임, 아이디, 실명 순서로 선택합니다. 연속 작성자의 아바타와 이름은 묶고 빈 반응 영역의 높이를 제거했습니다.

입력 상태는 인증된 Mattermost WebSocket으로 송수신합니다. 작성 내용은 보내지 않고 방·사용자 식별자만 사용하며, 전송은 3초 간격으로 제한하고 상대 입력 표시는 마지막 신호 후 약 6초에 만료됩니다. 서버의 WebSocket 연결과 입력 표시 설정이 허용되어야 합니다. mage 등 표준 이모지 별칭은 로컬 Unicode 데이터로 표시하며 서버 사용자 이모지가 있으면 우선 사용합니다.

## 원문 탐색 뒤로 가기와 서버 관리

공유 원문으로 이동할 때 이전 방, 검색 조건, 불러온 메시지, 작성 내용과 화면의 메시지 기준 스크롤 위치를 보관합니다. 상단 뒤로 버튼 또는 Alt+왼쪽 화살표로 돌아갈 수 있고 원문 탐색 기록은 최대 20단계이며 로그아웃하면 지웁니다. 이미지가 늦게 로드되어도 읽던 메시지 위치를 유지합니다.

서버 관리는 설정의 **서버 전체 관리**에서 Moyeo 자체 관리 화면을 엽니다. 사용자·역할·채널·멤버·팀·파일 저장소·SMTP·서버 일반 설정을 공식 REST API로 조회·저장하고 역할·권한 목록, 서버 로그와 라이선스를 조회합니다. 서버의 최신 시스템 관리자 역할을 매 요청마다 확인하며 서버 권한·라이선스 제한은 그대로 적용됩니다.

관리 화면은 앱의 로컬 UI이며 별도 서버 웹 페이지를 불러오지 않습니다. 서버 웹 클라이언트의 데스크톱 앱 선택 화면이나 쿠키 전달에 의존하지 않습니다. 저장은 변경한 허용 항목만 PATCH하고, 서버가 환경 변수로 고정한 항목은 읽기 전용으로 표시합니다.

GIF만 전송하면 빈 텍스트 말풍선·첨부 파일 자동 문구·파일명·종류·용량을 채팅에서 숨깁니다. 원본 미리보기와 자료 모음에서는 파일 정보와 저장 기능을 계속 사용할 수 있습니다.

`node tests/management-pins-ui.cjs`는 앱 자체 관리 화면에서 사용자 역할·이메일·세션·토큰, 채널·공개 범위·멤버 역할, 저장소·SMTP 저장과 테스트, 비밀값 보호, 환경 변수 잠금 및 관리자 권한 회수를 검증합니다.

## 실시간 동기화와 플로팅 채팅

0.10.0은 기존 4초 REST 반복 조회를 제거했습니다. 채팅 수신용 인증 WebSocket 하나를 메인 창과 플로팅 창이 공유합니다. 서버의 새 메시지·수정·삭제·이모지 반응 이벤트를 바로 반영합니다. 클라이언트가 DB에 직접 연결하거나 조회하지 않습니다. 권한별 이벤트 전달은 Mattermost 서버가 수행합니다.

최초 접속·방 열기·이전 대화·검색·전송·읽음 처리는 REST API를 사용합니다. 재접속이나 이벤트 누락 감지, 채널·사용자·환경설정 변경 시에는 필요한 목록을 다시 조회합니다. WebSocket의 30초 ping은 연결 유지용이며 메시지 목록 조회가 아닙니다. 연결이 끊기면 상태를 표시하고 자동 재연결해 누락을 복구합니다. System Console은 서버의 원래 웹 앱이므로 자체 연결 동작을 따릅니다.

방 상단 ↗ 버튼으로 각 채팅방을 별도 창에서 엽니다. 같은 방은 기존 창을 다시 표시하며, 각 창은 작업 표시줄에 나타나고 핀 버튼으로 항상 위에 둘 수 있습니다. 새 메시지가 온 비활성 창은 작업 표시줄에서 깜빡이고 해당 창을 확인하면 멈춥니다. 플로팅 창 X는 그 창만 닫고 메인 창 X는 트레이로 숨깁니다.

메시지 영역 위로 스크롤하면 별도 버튼 없이 이전 대화를 불러옵니다. 이미지·답글을 뒤늦게 불러와도 읽던 말풍선 위치를 유지합니다. 입력창에서 @를 쓰면 서버 계정 추천을 표시하며 닉네임·아이디·아바타로 구분합니다. 방향키로 선택하고 Enter 또는 Tab, 마우스로 삽입합니다. 선택용 Enter는 메시지를 전송하지 않습니다. 실제 멘션은 @username으로 전송합니다.

방 상단 검색 버튼 또는 Ctrl/Cmd+F로 서버 메시지·파일·사용자를 검색합니다. in:, from:, before:, after:, on:, ext: 같은 Mattermost 검색식을 전달하고 팀·보관 채널·AND/OR 조건을 지정할 수 있습니다. 검색 결과에서 원문으로 이동하고 뒤로 버튼으로 원래 방과 위치에 돌아갑니다. 검색 가능 범위는 서버 권한과 검색 엔진 설정을 따릅니다.

추가 UI 검증: node tests/windows-search-ui.cjs, node tests/session-ui.cjs, node tests/console-ui.cjs. 테스트 서버에서 두 창의 단일 WebSocket 공유, 대기 중 메시지 조회 없음, 이벤트 수신·수정·삭제·반응·재접속 복구, @ 추천 키보드/마우스 선택, 플로팅·검색·관리 권한을 확인합니다. 실제 운영 서버의 모든 버전·플러그인 조합을 검증한 것은 아닙니다.

문서 미리보기는 번들에 포함한 Mozilla PDF.js와 로컬 XML 파서를 사용합니다. 외부 문서 변환 서비스로 첨부나 로그인 정보를 전송하지 않으며, 문서를 미리 보기 위해 사용자가 저장 위치를 선택할 필요가 없습니다. PDF 글꼴·CMap 등도 로컬 번들에서 읽습니다. `node tests/documents-ui.cjs`는 PDF 두 페이지의 실제 렌더링과 확대, Office·HWPX 내용, 저장 후 열기·폴더 열기, 기본 앱 실패·파일 이동·로그아웃 정리를 검증합니다.

이미지 첨부는 원본 비율을 유지하며 가로 최대 520px·세로 최대 640px 안에서 전체를 표시합니다. 채팅 이미지 아래 파일명·종류·용량은 숨기고, 클릭 미리보기와 자료 모음에서 확인합니다. 잘린 서버 썸네일 대신 고해상도 미리보기를 사용하며 실패하면 원본으로 전환합니다. 문서·표·프레젠테이션 등은 운영체제에 연결된 프로그램의 파일 아이콘을 표시합니다. 설치된 앱과 파일 연결에 따라 아이콘이 달라지며, 조회 실패 시 확장자 표시를 사용합니다. 확장자별 아이콘은 캐시하며 첨부 본문을 내려받거나 실행하지 않습니다.

한 메시지에 이미지가 2장 이상 첨부되면 채팅 안에서 2열(9장 이상은 3열) 그리드로 묶습니다. 각 칸은 이미지 전체가 보이도록 비율을 유지하며, 파일·영상은 별도 카드로 유지합니다. 이미지를 클릭하면 해당 원본을 크게 열고 좌우 이동·확대·저장을 사용할 수 있습니다. 답장 인용의 여러 이미지도 그리드로 표시합니다.

## v0.14.7 Windows 설치 중 종료 감지 수정

설치·제거 시 폴더 접두어 전체를 실행 중인 앱으로 판단하던 기본 감지를 교체했습니다. 같은 Windows 세션의 정확한 설치 경로 Moyeo.exe만 확인하며, 설치기·제거기·다른 폴더의 앱을 종료 대상으로 삼지 않습니다. 설치 중 실행 앱 종료에 동의하면 --quit-for-install로 정상 종료를 요청하고, 종료되지 않는 이전 버전·잔여 프로세스만 해당 경로에서 정리합니다. 일반 창 닫기는 계속 트레이로 숨깁니다. 사용자 데이터 삭제·자동 설치·자동 재시작 동작은 추가하지 않습니다.

## v0.15.0 기존 Mattermost 관리 기능과 메시지 핀

설정 맨 위에서 **내 계정 설정**, **서버 전체 관리**, **이 기기의 앱 설정**을 구분합니다. 일반 계정은 본인의 닉네임·이름·직책·이메일·비밀번호만 서버 API로 수정하고, 외부 인증 계정의 비밀번호는 해당 인증 서비스에서 변경합니다. 역할이나 다른 사용자 ID를 개인 API로 전달할 수 없습니다. 앱 이름·로고·테마·소리·시작 실행은 계속 로컬 설정입니다.

**서버 전체 관리**는 서버가 확인한 `system_admin` 계정에게만 제공됩니다. 0.15.4부터 기존 웹 관리창을 Moyeo 자체 UI로 교체했습니다. 사용자 검색·관리자 역할 부여·활성화·세션·팀·토큰·비밀번호·이메일, 채널 정보·공개 범위·보관·복원·멤버 역할, 로컬/S3 저장소와 SMTP 저장·테스트를 제공합니다. 추가 메뉴로 팀, 역할·권한 조회, 로그, 라이선스와 서버 일반 설정을 제공합니다. 비밀번호와 저장소 키를 앱 설정 파일에 저장하지 않습니다.

관리 화면 진입과 각 API 요청에서 서버의 최신 역할을 재검증합니다. 일반 계정의 직접 호출도 거부하고, 열린 화면에서 권한이 회수되면 다음 요청에서 편집 내용을 지우고 차단합니다. 파일 저장소의 경로는 Mattermost 서버 또는 컨테이너 안의 경로입니다. 저장 경로 변경은 기존 파일을 자동 이전하지 않습니다.

메시지 우클릭 **메시지 고정/고정 해제**, 채팅방 상단 **📌 개수**에서 서버의 고정 메시지를 조회하고 원문으로 이동합니다. 핀은 개인 즐겨찾기나 창의 항상 위 핀과 다르며 해당 채널에 공유됩니다. 다른 Mattermost 클라이언트의 고정·해제 이벤트도 반영합니다. 핀 권한은 Mattermost의 채널 읽기 권한과 서버 정책에 따르며 일반 채널 구성원도 서버가 허용하면 사용할 수 있습니다.

`npm run test:management`는 개인 프로필·비밀번호 수정, 역할 상승 차단, 핀·원문 이동·403 거부·실시간 갱신, 자체 관리 UI의 실제 API 저장 흐름, 비밀값 보호·환경 변수 잠금·권한 회수를 테스트 서버에서 확인합니다. 운영 서버의 SMTP·저장소는 테스트 중에 변경하지 않습니다.

## v0.15.1 구버전 설치 교체 오류 수정

0.14.5 배포 파일의 내장 제거 프로그램에서 CRC 불일치를 확인했습니다. 앱을 꺼도 0.15.0 설치 과정에서 이 구버전 제거 프로그램이 실패해 `Moyeo cannot be closed`가 표시될 수 있었습니다.

0.15.1은 등록된 기존 설치 경로의 앱 파일을 확인한 뒤 새 설치 파일에 포함된 검증된 제거 프로그램으로 교체를 진행합니다. 기존 파일 잠금·원상 복구 처리와 `--updated` 데이터 보존 경로를 유지합니다. 로그인 정보와 개인 설정을 먼저 지울 필요가 없습니다. 설치 EXE와 내장 제거 프로그램의 CRC를 모두 검사해 실패한 산출물은 배포하지 않습니다. 설치가 계속 실패하면 `%TEMP%\Moyeo-install.log`에 교체 대상과 제거 프로그램 종료 코드가 기록됩니다.

검증은 전용 임시 설치 경로와 독립 레지스트리 키를 사용한 실제 NSIS 설치·업그레이드·제거로 수행합니다. 정상 및 손상된 구버전 제거 프로그램, 실행 중인 앱, 다른 폴더의 동명 앱, 잘못된 설치 경로, 로그인·설정 보존을 확인합니다.

## v0.15.2 누락된 설치 폴더 복구

설치 등록은 남아 있는데 프로그램 폴더가 없거나 실행 파일·ASAR 일부가 빠진 경우 0.15.1의 보호 검사에서 설치가 중단되던 문제를 수정했습니다. 불완전한 기존 설치는 제거 프로그램을 실행하거나 폴더를 삭제하지 않고, 선택한 대상에 정상 파일을 다시 설치한 뒤 등록 정보를 갱신합니다. 이 복구 경로에서는 알 수 없는 기존 파일도 보존합니다. 정상 설치의 파일 잠금·원상 복구 처리, 손상된 구버전 제거 프로그램 대응, 로그인·설정 보존은 유지합니다.

## v0.15.3 Windows 알림과 설치 후 실행

Windows 알림의 표시 이름과 실행 대상을 Moyeo로 등록합니다. 개발용 Electron과 검사 프로필에서는 네이티브 알림 등록을 사용하지 않아 설치된 앱의 바로가기·알림 활성화 경로를 덮어쓰지 않습니다. 이전에 Moyeo AppID로 잘못 생성된 개발용 Electron 바로가기는 백업 후 정리합니다.

알림 클릭은 기존 알림 객체뿐 아니라 Windows 활성화 콜백으로도 처리합니다. 앱 재시작 중 클릭은 로그인과 채널 화면 준비 후 전달하고 계정이 일치할 때만 해당 대화방을 엽니다. 설정의 **알림 테스트**로 현재 대화방 알림을 표시할 수 있습니다. 설치 완료 후 실행은 바로가기 파일 대신 설치된 EXE를 직접 대상으로 사용합니다.
